# Instrucciones para continuar el proyecto

Antes de modificar este repositorio, lee `docs/REGISTRO_CAMBIOS.md` para conocer las peticiones, decisiones y comprobaciones pendientes. Actualízalo con cada cambio solicitado, indicando qué se ha hecho, qué se ha comprobado y qué queda pendiente. No incluyas contraseñas, claves ni otros secretos.

El propietario trabaja en dos ordenadores y solicita que cada cambio, incluido el registro, se guarde en Git y se suba al remoto `origin`. Comprueba el estado del repositorio antes de hacerlo y no incluyas cambios ajenos sin identificarlos.
